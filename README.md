Analisador de Vendas

Projeto em Python que lê dados de vendas, faz a limpeza, calcula indicadores,
gera gráficos e exporta um relatório em Excel.

O que o projeto faz
- Gera uma base fictícia de 1.000 vendas, com duplicatas e campos vazios
- Limpa os dados com pandas
- Calcula receita total, ticket médio e rankings por produto e região
- Gera gráficos com matplotlib
- Exporta um relatório em Excel com várias abas
